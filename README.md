## Kompatibilitas rumus
- File bab memakai LaTeX di antara `$$ ... $$`, yang dirender GitHub sebagai persamaan.
- File `RUMUS-UNIKODE-ONLYOFFICE.txt` memakai simbol Unicode (√, ², ₀, θ, Σ) agar bisa disalin ke ONLYOFFICE atau Word tanpa berubah menjadi kode LaTeX.
- Saat menyalin ke ONLYOFFICE, salin rumus dari file Unicode tersebut. Untuk rumus bertingkat yang kompleks, gunakan **Sisipkan > Persamaan** bila ingin tampilan pecahan/akar bertingkat.

## Konvensi
- Gunakan satuan SI.
- Gunakan g = 9,8 m/s² atau 10 m/s² sesuai instruksi soal.
- Rumus gerak peluru untuk waktu total dan jangkauan berlaku jika ketinggian awal dan akhir sama.
- Pastikan kalkulator berada pada mode DEG saat sudut dinyatakan dalam derajat.
